# senwenskill · 森文的 Skill 仓库

把值得反复使用的 AI 工作流做成 Skill，减少重复复制提示词。

每个 Skill 独立放在 `skills/` 下，后续会继续添加。

## 已收录

| Skill | 名称 | 用途 |
| --- | --- | --- |
| [gaoshouru](skills/gaoshouru/) | 发掘高收入 | 逐步梳理经历、发现被低估的技能、比较职业与副业机会，形成个人报告和 90 天行动计划 |

## 安装“发掘高收入”

把下面这句话发给支持 Skill 安装的 Codex：

```text
请使用 $skill-installer 安装这个 GitHub Skill：
https://github.com/baishiyi2023-hash/senwenskill/tree/main/skills/gaoshouru
```

也可以把仓库链接和路径一起交给你的 AI Agent：

```text
请从 https://github.com/baishiyi2023-hash/senwenskill
安装 skills/gaoshouru，安装后告诉我如何调用。
```

不同 Agent 的安装入口可能不同；需要它支持读取 `SKILL.md`。Codex 的安装说明见 [官方文档](https://learn.chatgpt.com/docs/build-skills)。

## 开始使用

安装后，在 Codex 输入：

```text
使用 $gaoshouru，帮我发掘高收入的可能性。请一步步问我，最后生成报告。
```

也可以先给一段经历：

```text
使用 $gaoshouru。
我做过……，主要负责……，做成过……。
我想优先考虑涨薪 / 跳槽 / 副业，每周可以投入……小时。
请结合我的情况一步步引导，不要一次把所有问题都抛给我。
```

不需要先准备一份完整简历。可以隐去姓名、公司、客户，薪资可以给范围，也可以不提供。

## 它会怎样带你走

先补齐必要背景，再按 7 个步骤推进。每一步先给分析，再用一个关键问题让你校正或选择，下一步继续使用已经得到的结果。

| 步骤 | 你会得到什么 | 对应原帖 |
| --- | --- | --- |
| 1. 发现隐藏技能 | 有经历依据的技能清单，以及可能付费的人 | 第 1 条 |
| 2. 把经验变成产品 | 服务、咨询、数字产品或自由职业的初步方案 | 第 3 条 |
| 3. 寻找额外收入机会 | 成本、时间、难度、验证方法的对比 | 第 2 条 |
| 4. 寻找更高薪方向 | 可迁移岗位、适配理由和能力缺口 | 第 5 条 |
| 5. 设计 AI 辅助服务 | 符合可用时间的服务与人工验收方式 | 第 6 条 |
| 6. 选定优先路线 | 一条主线、一条备选和选择理由 | 第 4 条 |
| 7. 制定 90 天计划 | 每周行动、时间预算、验收与调整条件 | 第 7 条 |

完成后生成《发掘高收入 · 个人机会与 90 天行动报告》，包括技能证据、机会比较、优先路线、90 天计划和未来 48 小时的第一步。支持从中途继续；信息不足时会明确标注，避免编造能力或收入。

默认是对话引导。只有你明确要求直接出报告时，才使用已有资料一次生成，并列出仍需验证的假设。

## 来源与改编

灵感来自 [Raúl | Productividad & IA 的 X 线程](https://x.com/Raul_IA_Prod/status/2084050182514049513)。本 Skill 对原帖的七个方向做了中文改编，重排为“挖技能 → 找机会 → 定路线”，增加分轮访谈、证据校验、路线选择与最终报告。

原帖的美元目标和每周时间条件均改为使用者自定参数。这里提供职业与服务机会分析，实际收入取决于需求、能力、执行与市场验证。详细对应关系见 [来源说明](skills/gaoshouru/references/sources.md)。

使用过程中产生的个人经历与报告保存在使用者自己的工作区，不需要上传到这个仓库。
